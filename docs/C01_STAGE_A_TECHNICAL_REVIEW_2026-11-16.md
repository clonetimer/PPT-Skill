## 三、必须完成的修订与验证

**P1（签核前必须完成）**

1. **统一节点数**：若 Total graph 与 Input 保持每层 3 节点，建议将每个 B_i 子图亦改为 3 节点；或在图中明确声明子图与组合图各自为不同的非一一对应示意。对于“图合并”教学图，优先建议三处一致。
2. **明确频带可变性**：改为 B1, B2, B3, …, B_N，或保留四个可见框并在 B3 与 B_N 之间加明确省略号、添加“示意频带，非固定四带”的注释。
3. **补齐拓扑核验依据**：提供 README 提及的 docs/C01_IMAGE2_STAGE_A_CANDIDATE_V2.md 及精确虚线连接核对清单；逐条编号核验“九条”的统计口径（仅跨频带虚线？是否包括其它连线？），明确哪些是示意、哪些必须与作者图完全对应。

**P2（建议修订）**

4. 在分类端或边界框中标示“5-class illustrative output”，以免被理解为方法固定五类。
5. 保留 IR/SR 术语差异说明；如能查到论文正文或图注，再补充“原图 IR / 摘要 SR”的准确对应关系。
6. 适度增粗主要连接线、放大右侧说明，降低多重交叉虚线密度；对 1080p 投影与常规会议室距离分别验收。
