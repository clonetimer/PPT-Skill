# Independent-paper generalization trials (2026-11-13)

## Purpose

MMGraph-Agent exercises a dense multimodal retrieval architecture and a composite benchmark figure. These two additional papers were selected to test whether the FigureSpec-first vector workflow transfers to unrelated scientific visual grammars without adding paper-specific renderer code.

Both trial figures are **source-visible redraws**, not pixel replicas. The original author PDFs and screenshots are not redistributed in this repository. Each candidate is generated by the repository's `tools/render_figure_spec.py` from an independent JSON specification.

## Trial 1 — Mamba selective state-space model

- Source: Gu and Dao, [Mamba: Linear-Time Sequence Modeling with Selective State Spaces](https://arxiv.org/abs/2312.00752), Figure 1.
- Figure family: sequence/state-space dataflow with input-dependent parameter selection and hardware memory hierarchy.
- Source-critical content retained:
  - hidden-state flow from `hₜ₋₁` to `hₜ`;
  - input/output features `xₜ` and `yₜ`;
  - parameter blocks `A`, `Bₜ`, `Cₜ), and discretization `Δₜ`;
  - the `Project → Selection Mechanism → Δₜ` path;
  - GPU SRAM and GPU HBM hierarchy.
- Simplification: four visible state lanes are schematic; the caption separately records the paper's example dimensions `D=5`, `N=4`. The drawing does not assert that the visible line count is a tensor dimension.

## Trial 2 — Swin Transformer shifted windows

- Source: Liu et al., [Swin Transformer: Hierarchical Vision Transformer using Shifted Windows](https://arxiv.org/abs/2103.14030), Figure 2.
- Figure family: spatial partitioning and cross-window connectivity.
- Source-critical content retained:
  - two successive layers;
  - an 8×8 patch map;
  - regular 4×4 windows in Layer `l`;
  - a half-window shift of (2,2) patches in Layer `l+1`;
  - the resulting 3×3 clipped shifted-window regions and the local-window/patch legend.
- Simplification: source image thumbnails are replaced with neutral editable patch cells. This preserves the partition semantics, not the source photographs.

## Acceptance boundary

- The source topology and labels are checked against a separate expected-topology fixture, not only against each drawing's own declarations.
- Structural PASS and LibreOffice rendering do not establish pixel-level visual similarity.
- The Swin redraw deliberately omits source image textures.
- The Office 2016 preflight is a conservative OOXML package check, not a Microsoft PowerPoint 2016 runtime test.
- Before publication use, a domain reader should verify all scientific semantics and inspect the final-size PowerPoint rendering on the target Office version.

The trial demonstrates that the workflow can represent both sequential state-space dynamics and spatial window partitioning with editable native PowerPoint objects. It does not establish universal one-pass reproduction for arbitrary research figures.
