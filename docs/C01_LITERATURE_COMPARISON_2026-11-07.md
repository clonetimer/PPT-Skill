# C01 生成 PPT 与论文图的差异审查（2026-11-07）

## 审查范围与判断标准

对照对象是 Lee 等（2026）的[出版社图形摘要](https://ars.els-cdn.com/content/image/1-s2.0-S0952197626015575-ga1_lrg.jpg)、[论文页面的摘要与方法概述](https://www.sciencedirect.com/science/article/pii/S0952197626015575)及[作者实验室页面](https://hai.snu.ac.kr/bbs/board.php?bo_table=sub4_1_a&wr_id=251)。生成物为 `dist/C01_composite_defense_slide_v74.pptx`、其 PDF/PNG 预览，以及 `dist/DECK01_c01_defense.pptx` 的第 2 页及 PDF/PNG。出版社 JPEG 的本地核对哈希见 `docs/C01_V76_SOURCE_CORRECTION.md`；原图不随仓库分发。

本审查按是否改变观众对**方法步骤、信息流、科学作用或输出**的理解分级。只有图形摘要和公开页面可核实；不能据此断言与论文所有正文图、精确邻接矩阵或实验数值完全一致。PPT 是答辩用结构重绘，不以像素一致为目标。未进行真实投影距离的可读性测试。

| 差异 | 论文可见内容 | 当前生成 PPT | 判断与影响 |
|---|---|---|---|
| OCF 后的频带构建 | 方法概述明确为两阶段：OCF 的 notch filter 去除主导运行成分，随后用 band-pass filters 构建每个频带的子图。图形摘要在 OCF 后展示按频带划分的子图。 | 顶部从 `OCF / notch filter` 直接画到 `Band subgraphs`，没有标出带通滤波。 | **重要遗漏。** 高层流程仍能读出“频带子图”，但观众可能以为 OCF 直接生成子图。讲解方法时应补上 `band-pass filtering` 的步骤或直接标签。 |
| OCF 的科学作用 | 图形摘要在滤波前后画出不同波形及 `Fault sensitivity` 的变化；论文概述指出去除运行成分使细微故障特征更可见。 | 只写 `Operational component removed`，未表达故障特征显露/敏感性变化。 | **重要的解释缺口。** 不会颠倒处理顺序，但弱化“为什么过滤”的因果说明。若此页承担方法贡献说明，应加一处可核实的前后对比或简短文字。 |
| 频带子图之间的关系 | 图形摘要把频带子图沿频率方向堆叠，并以虚线连接，标为 `Total graph`；论文摘要说各频带子图相连形成最终图。 | B₁/B₂/B₃/Bq 各以箭头汇入一个节点，再到单个通用网络图；没有显式跨频带连接。 | **重要的结构简化，存在误读风险。** “多个频带共同形成总图”仍在，但星形汇入容易被读成特征聚合，而非子图相连。应明确标为示意汇合，或画出跨频带连接；不能据图声称精确邻接结构。 |
| SEANet 主路径与分支 | 输入→GCN→pooling→GCN→pooling→上方 SR→求和→Dense→故障分类；输入→EA→首个 GCN；首个 pooling→下方 SR→求和。 | 当前复合页 PPTX/PDF 与三页 deck 的 PPTX/PDF 已显示对应路径、两个 SR 和 Dense。 | **关键科学关系已保留。** 旧版 EA→下方 SR 捷径和缺少 Dense 曾属实质错误，已由 V7.6 修正；不得以历史 QA 截图代表当前 PPTX。 |
| 传感器和图节点外观 | 图形摘要使用传感器照片、复杂波形和堆叠图节点。 | 用矢量传感器符号、规则化波形与示意节点替代，并明确说明 adjacency 为 schematic。 | **可接受的非关键外观差异，前提是持续披露。** 这些形状不支持推断真实传感器型号、波形数据或数值邻接矩阵。 |

## 下一步

1. 优先把带通滤波与跨频带连接的示意边界补进 C01 FigureSpec 和 PPT；保留“未知精确邻接”的说明。
2. 若此页要解释 OCF 的贡献，加入受原图和论文文字支持的“运行成分降低、细微故障特征更可见”提示；不要编造幅值或敏感性数值。
3. 生成及交付时核对 PPTX、PDF 和 PNG 的关键标签与连接，避免只检查 PPTX/PDF 文本后仍发放旧预览。
4. 上述判断是对公开图形摘要和文字的独立比对，不替代机械故障诊断领域评审和真实终尺寸检查。
